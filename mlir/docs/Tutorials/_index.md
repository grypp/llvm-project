# Tutorials

This section contains multiple MLIR tutorials.
See [Toy tutorial](toy) for an introduction to using MLIR infrastructure.
See [Transform dialect tutorial](transform) for an introduction to using and extending of MLIR's Transform dialect.

See [mlir-dsl](../../tools/mlir-dsl/README.md) for a Python DSL base layer: a tracing core with native control-flow capture, explicit SCF builders and a JIT runtime built on the Python bindings, with the dialects as plugins and `mlir.mlir_dsl` as the reference sub-DSL.
