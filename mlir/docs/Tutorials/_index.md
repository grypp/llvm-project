# Tutorials

This section contains multiple MLIR tutorials.
See [Toy tutorial](toy) for an introduction to using MLIR infrastructure.
See [Transform dialect tutorial](transform) for an introduction to using and extending of MLIR's Transform dialect.

See [mlir-dsl](../../tools/mlir-dsl/README.md) for a Python DSL base layer on the Python bindings: a tracing core that stages annotated values into MLIR ops, native control-flow capture and explicit builders for `scf`, a pass pipeline each DSL spells itself, and an optional compiler plugin over the `ExecutionEngine`; `mlir.mlir_dsl` is the reference sub-DSL its tests use.
